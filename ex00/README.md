# Personal Portfolio

## About the Project

This is a personal portfolio website created to introduce myself, showcase my technical skills, and present my projects.

## Features

- About Me section
- Skills grid
- Project showcase
- Hobbies section
- Contact form
- Footer

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` - Website structure and content.
- `style.css` - Styling and responsive layout.
- `script.js` - Interactive functionality.
- `assets/` - Images and other resources.

## Responsive Design

The website is designed to work across desktop, tablet, and mobile screen sizes.

## Projects

The portfolio showcases practical projects with images and links to their repositories.

## Contact

The contact section allows visitors to get in touch.

## Development

This portfolio was built from scratch using HTML, CSS, and JavaScript without external templates or CSS frameworks.
